# Cappi Shopper — бот тайного гостя

Телеграм-бот, який веде перевіряючого по чек-листу: замовив — натиснув,
отримав — натиснув, оцінив, сфотографував. У кінці адміни отримують
звіт з оцінкою по розділах, часом доставки і критичними провалами.

Без залежностей — стандартна бібліотека Python 3.12.

## Запуск

```
cp api.env.example ~/.shopper/api.env    # заповнити токен
python3 selftest.py                      # має сказати ok
python3 bot.py
```

Прогін без Telegram — `python3 tests/dryrun.py`: друкує весь діалог
від першого «/start» до звіту.

## Сервер

`cappi-bot`, контейнер `cappi-shopper` поруч із `cappi-core`:

```
docker compose -f deploy/docker-compose.yml up -d --build
```

Стан — у `data/` поруч із `deploy/`, змонтований як `~/.shopper`.

## Що де

| файл | за що відповідає |
|---|---|
| `сценарій.json` | питання, розділи, ваги — те, що правиться за ТЗ |
| `bot.py` | Telegram, екрани, маршрутизація |
| `перевірка.py` | хід перевірки, сесії, журнал |
| `звіт.py` | бали і текст звіту |
| `access.py` | ролі: перевіряючий, адмін |
| `сховище.py` | файли у `~/.shopper` |
| `selftest.py` | перевірка перед деплоєм |
