# Cappi Shopper — АРХІВ

> З 17.09.2026 бот тайного гостя живе у Loopa: репозиторій Review360,
> пакет `mystery/`. Вебхук `app.loopa.rest/telegram/mystery/1`, контейнер
> `cappi-shopper` на сервері зупинений, дані в `~/app/cappi-shopper/data`
> збережені. Логіку правити там, не тут. Цей репозиторій — історія
> етапів 1–2 (16.09.2026) і документи: ТЗ, API.md, запити до джерел.


Телеграм-бот з агентом, який веде програму тайного покупця Каппі за
[ТЗ v1.1](docs/ТЗ-тайники-v1.1.md): реєстр тайників, тижневі хвилі зі
слотами, персональні завдання з акцептом, анкета блоками, приймання з
автоперевірками, оцінка по групах, звіти в робочі чати, заявки на
виплату. Зараз — **етап 1 (MVP)**.

Без залежностей — стандартна бібліотека Python 3.12.

## Запуск

```
cp api.env.example ~/.shopper/api.env    # токен, id власника
python3 selftest.py                      # має сказати ok
python3 bot.py
```

`python3 tests/dryrun.py` — повний цикл на фальшивому Telegram: три
кандидати, хвиля, акцепт і відмова, анкета, приймання, виплата,
підтримка. Друкує весь діалог.

## Сервер

`cappi-bot`, контейнер `cappi-shopper` поруч із `cappi-core`:

```
docker compose -f deploy/docker-compose.yml up -d --build
```

Стан — у `data/` поруч із `deploy/`, змонтований як `~/.shopper`.

## Команди для компанії

`/syrve [+380… дата]` — чи бачимо замовлення · `/еталони` — прив'язати картки до Syrve ·
`/тікети` — відкриті тікети, закриття → повторна перевірка · `/місяць [YYYY-MM]` — зводка ·
`/реєстр` — CSV виплат · `/дайджест` — тижнева зводка і що агент зробив сам ·
`/чат` у групі — підключити її як робочий чат · `/роль <id> <роль>` — доступ.

| `анкета.json` | питання анкети блоками, ваги, критичні — правиться за ТЗ |

| `анкета.py` | збирає кроки анкети під завдання |
| `тайники.py` | реєстр, згоди, інструктаж, кулдаун, рейтинг, блеклист |
| `хвилі.py` | хвилі, слоти, черга, резерв |
| `завдання.py` | матриця покриття, план хвилі, генерація завдання |
